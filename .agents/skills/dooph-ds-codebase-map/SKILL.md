# Codebase map

Everything in `dist/` is compiled from `src/`, and parts of `src/` are generated by scripts in `scripts/`. Find any source file in [references/inventory.md](references/inventory.md) (exports, header contract, `"use client"` status). Change a generated file only by running its generator.

**Not for** the rules of component code, styling or tokens, or the steps for adding a component (see the related skills).

## Where things live

| Path | Holds |
|---|---|
| `src/index.ts` | The only public entry (`exports["."]`). Re-exports every `src/components/<Folder>/index.ts`, plus `cn`, `DS_TW_MERGE_CONFIG`, `DS_COLOR_TOKENS`, `resolveDsColor`, `DsColor`, `DsColorToken` |
| `src/components/<Folder>/` | One family: `.tsx` modules, `index.ts` barrel, stories, `constants.ts` for option consts (`IconSize` is in `Icons/BaseIcon.tsx`), internal modules (`Modal/dialogShell.tsx`, `MorphRotationShape/engine/`) |
| `src/utils/` | Public: `cn.ts`, `color.ts`. Internal: `composeRefs.ts` (`useComposedRefs`), `length.ts` (`toPxLength`). Generated: `twMergeTheme.ts` |
| `src/styles/tokens.css` | Every `--ui-*` token |
| `src/styles/build.css` | The shipped CSS entry: `index.css` with stories left out of the scan. Add nothing to it |
| `src/styles/index.css` | The Tailwind entry (Storybook's, and the build's through `build.css`): `@property` registrations, custom variants, the generated `@theme` block, `.text-style-*` roles, size utilities, animation systems and keyframes, `.ds-expr-*` helpers |
| `src/styles/dooph-component-tokens.css` | `ds-*` helpers: motion, focus, disabled, overlays, slider/progress geometry, sizing, chat prose. `ds-*` rules are in both stylesheets: grep both |
| `scripts/`, `bin/init.mjs` | Generators, lint, the `init-skills` bin: [references/build-and-scripts.md](references/build-and-scripts.md) |
| `skills/` | Consumer skills; they ship in the tarball |
| `.agents/skills/` | Maintainer skills (canonical). `.claude/skills/` and `.agent/skills/` are generated copies |

## Generated files: never hand-edit

| File | Regenerate with | Lint check |
|---|---|---|
| `@theme inline` block between the `__GENERATED_THEME_*__` markers in `index.css`; `src/styles/theme.css`; `src/utils/twMergeTheme.ts` | `npm run sync-tokens`, after editing `tokens.css` or the `.text-style-*`, `.h-*`, `.size-*`, `.min-w-*`… rules in `index.css` | "generated theme out of date" |
| `src/components/Icons/index.ts` | `npm run generate-icon-exports`, after adding or removing an `*Icon.tsx` | "icon barrel out of date" |
| `--ui-shape-morph-duration` / `--ui-shape-morph-ease` between the `__SHAPE_MORPH_EASE_*__` markers in `tokens.css` | `npm run generate-shape-morph-ease` (spring constants in `scripts/shapeMorphSpring.mjs`) | "shape-morph ease out of date" |
| `references/inventory.md`, the usage skill's `components.md`, the theming skill's `token-contract.md`, the generated block of the setup skill's `client-references.md` | `node scripts/generate-docs.mjs` | "generated doc references out of date" |
| `.claude/skills/`, `.agent/skills/` | `node scripts/sync-skills.mjs` | "skill mirrors out of sync with .agents/skills" |

## Build in one breath

`npm run build` = icon barrel, shape-morph ease, sync-tokens, tsup (which stamps `"use client"` and compiles `build.css` to `dist/styles.css`). `index.css` opens with `@import "tailwindcss" source(none)` plus `@source "../**/*.{js,ts,jsx,tsx}"`, so Tailwind scans only `src/`, never docs or skills. Storybook compiles `index.css` (stories included); `build.css` is `index.css` plus `@source not` for stories. A utility ships only if its class name appears in a non-story file under `src/`.

## Rules

- **Never run `npm run build`, `build:watch` or `prepublishOnly` in the main checkout.** They rewrite `Icons/index.ts`, `tokens.css`, `index.css`, `theme.css` and `twMergeTheme.ts`, and run no lint. Prevents: a "verification" that churns tracked files and checks nothing. Run them in a scratch worktree; `build:js`, `build:css` and `build-storybook` write only gitignored output.
- **Never run `prep-release:*`.** It bumps the version, builds and pushes tags. Prevents: an unplanned release.
- **Edit skills in `.agents/skills/` only**, then sync. Prevents: a mirror edit the next sync overwrites.
- **After a value change, check every comment that states the old value.** Find the uses with the blast-radius greps in dooph-ds-editing-tokens, and also grep the old literal (the old pixel value, say) across `src/`. Read every comment near each use: inline, JSDoc or header contract. Flag broken arithmetic in the hand-back; never quietly reword it. Prevents: an inline sum of parts that adds up to the old value, in a file with no header contract, going silently false.

## Common mistakes

| What the agent said | What is true |
|---|---|
| "Now add the Tailwind aliases in both theme.css and index.css." | Both are generated. Run `npm run sync-tokens`. |
| "Everything passes — type-check and build are clean." | A build is not lint, and it rewrites tracked files. Run `npm run lint`. |
| "Type-check passes." | `npm run lint` = `tsc --noEmit`, then `check-conventions.mjs`. tsc alone checks no convention. |
| "I should update the comment to reflect the new value" | A comment whose sum no longer balances is a design question. Flag it in the hand-back with the slack it reveals; don't reword it. |

## Verification

- REQUIRED before any hand-back: `npm run lint` exits 0.
- Edited `check-conventions.mjs`: also `node scripts/check-conventions.mjs --fixtures`.
- Changed the build or `package.json`: build in a scratch worktree, then `npm pack --dry-run`.
- Storybook: the `.claude/launch.json` "storybook" entry serves port 6007 and may already be the maintainer's, so reuse it. `npm run storybook` serves 6006.
