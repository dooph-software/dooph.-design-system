Scratch: `docs/audit/_work/scratch/V1/` (rsc-hooks2.mjs + rsc-register2.mjs = a Node module-customization
hook that approximates an RSC bundler: any module whose first statement is `"use client"` is replaced
by a client-reference stub, and `import {x} from "react"` inside the package resolves to a shim over
React's `react-server` build with webpack-style `undefined` for missing names; rsc-chunks.mjs imports a
chunk and calls the component's render function directly).
