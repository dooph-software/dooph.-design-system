# Rules for every agent working on the remediation (read fully before editing)

Repo: `C:\Users\stick\Github\dooph\dooph-Design-System`. These rules are mandatory, and a brief cannot override them.

1. **Never commit, stage, push, tag or publish.** Don't run `git add`, `git commit`, `git stash`, `git checkout -- <file>`, `git restore` or `git reset`. Never run `npm run prep-release:*`. Never change `package.json` `version`. Install nothing and add no dependency.
2. **Stay in your lane.** Edit ONLY the files your brief lists. Other agents are editing other files at the same time. If you need a change in a file outside your list, don't make it: report it in your hand-back.
3. **Header contracts (AGENTS.md).** Read a file's top `## behavior` / `## constraints` block before editing it.
   - If your change contradicts a constraint, STOP that part, leave it undone, and report it plainly. A skipped item is a complete result.
   - If your change alters described behaviour, update the header in the same edit.
   - Don't add a contract to a file that has none unless it now carries a real invariant.
4. **Docs are deferred.** Don't edit CHANGELOG.md, README.md, `skills/**`, `.agents/**`, `.claude/**` or AGENTS.md. Instead, write your change record to the file your brief names under `docs/audit/_work/changes/`. Use the format in `docs/audit/CHANGES.md`, with these fields:
   - files, what changed, consumer impact;
   - breaking: `no` or `yes — v6` with an exact old → new list;
   - verified;
   - docs owed.

   Plain words first; audit IDs only in brackets.
5. **Generated files are never hand-edited:**
   - `src/styles/theme.css`;
   - the `__GENERATED_THEME_START__…END__` block in `src/styles/index.css`;
   - `src/components/Icons/index.ts`;
   - `src/utils/twMergeTheme.ts` (generated by `npm run sync-tokens`);
   - the generated `--ui-shape-morph-ease`.

   After editing `src/styles/tokens.css`, run `npm run sync-tokens`. If a new token must NOT become a Tailwind theme key (raw-var-only, like the button heights), add it to `EXCLUDED` in `scripts/sync-theme.mjs`.
6. **Repo conventions (enforced by the scoreboard). New code must not add to any count.**
   - **Motion:** only `--ui-motion-*` scale tokens, via `ds-*` helpers or `var()` in CSS. No `duration-N`, `ease-*`, `cubic-bezier` or `Nms` literals in components. Reduced motion comes from the single global rule in tokens.css. See `docs/audit/motion-scale.md`.
   - **Spacing and sizes:** only DS tokens and utilities.
     - Spacing scale: `xxxs` 2, `xxs` 4, `xs` 6, `sm` 8, `rg` 10, `md` 12, `lg` 16, `xl` 20, `xxl` 26, `xxxl` 42.
     - Heights: `h-button` 38, `h-button-sm` 34, `h-button-medium` 46, `h-button-big` 54, `h-button-micro` 28.
     - No arbitrary `[13px]` values, no Tailwind numeric spacing (`gap-2`), no raw `var(--ui-*)` inside className.
   - **Shared helpers:** focus uses the `ds-focus-*` helpers; disabled uses `ds-disabled-state` / `ds-radix-data-disabled`.
   - **Discrete options:** a dot-accessible const object plus a same-named type (`export const XVariant = {...} as const; export type XVariant = ...`), re-exported from `src/index.ts`. Keys are camelCase.
   - **Wrapper shape:** components are `forwardRef` with `displayName`. `cn(base…, className)` puts the consumer's `className` last; a consumer `style` merges last.
   - **Value controls:** `value` / `defaultValue` / `onValueChange(value)`.
   - **`"use client"`:** only when the module itself uses hooks, browser APIs, event-handler closures on host elements, or passes function props to a client component. The DS leaves data and control to the consumer.
   - **Size words:** `standard` is the base size key; never `default` or `small`.

   - Run `npm run lint`; it must exit 0.
   - Run `node docs/audit/_work/scratch/scoreboard.mjs` before and after. No number may go up because of your change. If one must, say exactly why.

11. **Never kill processes by name or image** (`taskkill /IM node.exe`, `pkill node`, `killall`). That stops the maintainer's own servers and tools. Stop only processes you started, by their PID, or by closing the server handle in your own script.
12. **Expressive details inside practical components** (a caret's shape, a hover nudge, an input decoration). Expressive components themselves (OutlineButton, CTA, shapes) are opt-in by use and are never switched. Each detail:
    - owns one token in `src/styles/tokens.css`, in the expression `:root` block, with a trailing `/* expression */` marker; its neutral value turns the detail off;
    - is read ONLY inside a `.ds-expr-*` helper rule (CSS), never from a component file;
    - is listed with its neutral value in the practical preset (`[data-ds-expression="practical"]` in `@layer ds.expression`), and in `EXCLUDED` in `scripts/sync-theme.mjs`;
    - gets a header-contract line in its component ("expressive detail X reads --ui-…; must stay neutralisable by the practical preset");
    - gets a "Practical" story with the component inside a `data-ds-expression="practical"` wrapper next to the default.

    Neutralised, the component must still be complete: no empty frame or gap where the detail was. Components never set expression tokens (no inline style, no arbitrary-property class, no `setProperty`). Run `node docs/audit/_work/scratch/expression-check.mjs` (also the last line of the scoreboard); it must PASS.
13. **Text is always set by a Text component.** This is the maintainer's standing rule; breaking it has already been caught once. Use `ButtonText`, `BodyText`, `LabelText`, `HeadingText`, `MonoText`, `CTAText`, `HeroButtonText`…, or `BaseText` with `variant` and typography props.
    - A span, div or p that holds text is a Text component (`<BodyText>`, `<BodyText as="div">`).
    - A root that owns its text renders through one with `as`: a button, a menu item, an input or textarea, a link, a kbd, or a Radix part such as `DialogPrimitive.Title`. For example, `<ButtonText as={Comp}>` or `<BodyText as={DropdownMenuPrimitive.Item}>`.
    - Typography is set once, on the element that owns the text. Descendants inherit it and never re-declare it.
    - Never write a `text-style-*` class outside `src/components/Text/`. That includes class recipes (`buttonVariants`, `toggleOptionVariants`, `menuItemClassName`) and stories.
    - Never set typography with utilities (`font-*`, `text-<size>`, `tracking-*`, `leading-*`) or inline `style={{ fontSize… }}`. Use the Text component's props (`fontSize`, `fontWeight`, `letterSpacing`, `lineHeight`, `axes`, `tabular`).
    - Two scoreboard lines, "Text styled without a Text component", must stay at 0. `node docs/audit/_work/scratch/text-leaves.mjs` lists every element that renders text, so you can check the rest by hand.
