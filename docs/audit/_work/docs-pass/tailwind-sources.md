# Tailwind source detection: what `source(none)` removed from the shipped CSS

Change: `src/styles/index.css` line 1 is now `@import "tailwindcss" source(none);`. The explicit `@source "../**/*.{js,ts,jsx,tsx}";` (all of `src/`, stories included) stays. Before, Tailwind v4's automatic detection also scanned the project root (README, skills/, docs/, docs/audit/) and turned class-like words found there into utilities in `dist/styles.css`.

## Method

- Scratch worktree of HEAD (0dac153) at `../ds-tw`, `npm ci`, `npm run build:css` (no earlier step is needed: emit-css only runs the Tailwind CLI and copies theme.css). Result: `before`.
- Copied the edited `src/styles/index.css` from the main checkout into the worktree, rebuilt: `after`.
- Class selectors extracted from each `dist/styles.css` by a small scanner that walks the CSS, skips comments, honours escapes and strings, and reads every `.class` in each rule's selector. Sorted and diffed with `comm`. (A first version mishandled escaped quotes and under-counted; the numbers below are from the corrected scanner.)
- Each removed class was searched as a whole token across every file under `src/` (all .ts, .tsx, .css, .svg; there are no .mdx files).
- The worktree is removed. The build was never run in the main checkout.
